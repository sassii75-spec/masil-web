# 마실 (Masil) — 어르신 맞춤 동네 나들이 & 복지·케어 서비스

> 💡 **'마실'이란?**
> 이웃에 놀러 다니거나 가볍게 잠깐 외출하는 일을 뜻하는 정겨운 순우리말(표준어)입니다.

어르신들, 실버 세대 및 부모님을 모시고 나들이를 떠나는 가족을 위한 **1시간/반나절 동네 마실 코스 추천 및 시·구립 복지관/데이케어센터 안내 웹앱**입니다.

---

## 🌟 주요 기능 및 리뉴얼 포인트

1. **5대 어르신 테마 카테고리**:
   - 🚶‍♂️ **걸어서 다녀올 마실 (도보 마실)**: 계단 없는 평지 산책로, 숲길, 탄천 산책길
   - 🚗 **차량으로 이동할만한 곳 (차량 마실)**: 호수 공원, 남한산성, 식물원 등 드라이브 명소
   - ⏱️ **1시간 다녀올 마실 (1시간 숏 마실)**: 쉼터와 차 한 잔으로 가볍게 머물다 오는 힐링 공간
   - 🍵 **속 편한 영양 한식 & 전통 찻집 (보양·다원)**: 곤드레 밥상, 토종 삼계탕, 수제 대추차 다원
   - 🏥 **시·구립 어르신 복지관 & 데이케어센터**: 노인종합복지관, 셔틀버스, 노인주간보호 데이케어, 치매안심센터

2. **어르신 전용 UI/UX & 디자인 파이프라인**:
   - **타이틀 폰트**: Google Fonts **Gowun Batang (고운바탕)** 적용
   - **본문 폰트**: **Noto Sans KR** 적용
   - **색상 팔레트**: 차분한 소나무 숲 그린(`#2E5A36`), 단풍/흙 앰버(`#C26D28`), 한지 라이트 크림(`#F9F8F5`), 차콜 블랙(`#1F2937`)
   - **어르신 가독성 기능**: 상단 **`[🔍 큰 글씨 모드]`** 원터치 확대 기능 제공

3. **안심 배려 지표 (Senior Care Badges)**:
   - 👨‍🦯 계단 없는 평지/슬로프
   - 🚗 넓은 주차 / 셔틀버스 운행
   - ☕ 쉼터 의자 다수
   - 🏥 건강·교양 강좌 / 데이케어 돌봄
   - 🍵 속 편한 영양 식사

4. **1초 어르신 맞춤 코스 조합 엔진 (`courseEngine.js`)**:
   - 어르신의 완만한 보행 속도(약 2.5km/h, 걸음수 약 1,800보)와 휴식 주기(산책/복지관 ➔ 찻집/식사 ➔ 쉼터)에 기반한 3-스탑 마실 동선 및 소요시간 산출.

## 📂 프로젝트 구조

```
Masil/
├── crawler/                      # 어르신 마실 & 복지관 크롤러 파이프라인
│   ├── crawl_silver_masil.py     # 어르신 산책/명소 수집 스크립트
│   ├── crawl_senior_welfare.py   # 시/구립 복지관 & 데이케어센터 수집 스크립트
│   ├── crawl_senior_dining.py    # 보양 한식 & 전통 다원 수집 스크립트
│   ├── merge_and_normalize.py    # 정규화 및 병합 스크립트
│   └── output/places.json        # 수집 및 정규화된 마실 데이터베이스 (18+곳)
└── web/                          # React + Vite 웹앱
    ├── index.html                # Gowun Batang 폰트 및 메타 태그
    └── src/
        ├── App.jsx               # 헤더, 검색, 큰글씨 토글, 탭 네비게이션
        ├── components/
        │   ├── HomeCurationView.jsx        # 5대 테마 큐레이션 및 마실 순우리말 안내
        │   ├── FilterBar.jsx               # 어르신 보행, 이동수단, 평지 전용 필터
        │   ├── CourseRecommendationModal.jsx # 3가지 어르신 코스 프리뷰 모달
        │   ├── CourseTimeline.jsx          # 타임라인 및 보행 걸음수 안내
        │   ├── PlaceDetailModal.jsx        # 평지, 쉼터, 주차, 복지 프로그램 상세
        │   ├── AboutModal.jsx              # '마실' 순우리말 어원 및 약속 모달
        │   └── CommunityView.jsx           # 이웃 마실 생생 이야기 (후기 커뮤니티)
        ├── data/places.json
        ├── lib/
        │   ├── constants.js                # 어르신 테마 카테고리 & 케어 태그 정의
        │   └── courseEngine.js             # 어르신 맞춤 코스 추천 엔진
        └── styles/
            ├── tokens.css                  # Gowun Batang 폰트 및 소나무/한지 색상 토큰
            └── app.css                     # 어르신 전용 대형 터치 & 고대비 스타일
```

## 🚀 실행 방법

```bash
cd web
npm install
npm run dev
```

- 브라우저에서 `http://localhost:5173` 접속
- `web/.env` 파일에 `VITE_KAKAO_JS_KEY` 설정 시 카카오맵 연동 지도 및 지오코딩이 활성화됩니다.
